# mclauncher# Appcdodi – Minecraft: Java Edition Launcher for Android

Personal, non-commercial launcher for Minecraft: Java Edition on Android (arm64).

- Sign-in with Microsoft (OAuth2 + PKCE). Only accounts that own Java Edition can play.
- No Mojang files are bundled: the game is downloaded from Mojang's official servers.
- Runtimes: OpenJDK 17/21/25 (Android builds), renderers gl4es and Mesa Zink (Vulkan, HDR10).
- Instances with Fabric, Quilt, Forge and NeoForge; mods from Modrinth.

Source code: `mclauncher_2.zip` in this repository.
